# 🏠 AirBnb Bookings Analysis

## 📊 Project Overview

This project involves an Exploratory Data Analysis (EDA) of AirBnb booking data to identify key trends, insights, and potential factors affecting customer bookings. The notebook provides an in-depth look at patterns in bookings, pricing, location, and user behavior.

- **Project Type:** EDA (Exploratory Data Analysis)
- **Contributor:** Himanshu Sharma
- **Goal:** Understand booking dynamics on the AirBnb platform

## 🗂️ Dataset

The analysis is based on a dataset containing information about AirBnb bookings. Key variables include:
- Listing details (location, price, host)
- Availability and reviews
- Booking dates and durations

*(Please ensure the dataset is placed in the appropriate directory before running the notebook.)*

## 📌 Key Steps in Analysis

1. **Data Loading & Inspection**  
   Initial loading and overview of data structure.

2. **Data Cleaning**  
   Handling missing values, data types, and formatting.

3. **Univariate and Bivariate Analysis**  
   Visual exploration of distributions and relationships.

4. **Geospatial Analysis**  
   Examining spatial patterns in AirBnb listings.

5. **Correlation & Statistical Insights**  
   Identifying factors affecting pricing and availability.

## 📚 Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib & Seaborn
- Jupyter Notebook

## 📈 Findings

Some of the insights derived from this analysis include:
- Pricing trends by neighborhood
- Seasonal patterns in bookings
- Relationship between reviews and price

## 📎 How to Use

1. Clone or download the repository.
2. Place the dataset in the same folder as the notebook (if not included).
3. Open `eda.ipynb` using Jupyter Notebook.
4. Run the cells step-by-step to view results and visualizations.
